"mismatch" is not corruption. A mismatch verdict reflects live mutable state (e.g. a Chrome profile or sqlite file that has changed since the NAS snapshot was taken) compared against a point-in-time backup copy — it does not by itself mean data loss or a bad file. Read the evidence badge: hash-proven = sha256 compared directly; path+size+mtime guess = same path/size/mtime found elsewhere, not byte-compared; no evidence = no counterpart found or checked yet, which is not proof the file is missing everywhere.
